# 풀이 습관

문제를 풀기 전에 입력 타입, 반환 타입, 예시를 먼저 확인한다. Lv.1부터 Lv.2까지는 복잡한 알고리즘보다 조건을 정확히 읽고 반복문 범위를 틀리지 않는 것이 더 중요하다.

## 기본 순서

1. 입력 타입과 반환 타입을 확인한다.
2. 예시를 손으로 한 번 계산한다.
3. 필요한 결과 변수나 배열을 정한다.
4. 반복문 범위를 정한다.
5. 예외 케이스를 확인한다.

## 자주 보는 예외 케이스

- 문자열 길이가 홀수/짝수인 경우
- 배열 길이가 1인 경우
- 숫자가 0 또는 1인 경우
- 대소문자가 섞인 경우
- 결과가 `int` 범위를 넘을 수 있는 경우

## 막혔을 때 기준

- 15분 동안 접근이 안 되면 예시를 직접 표로 써본다.
- 25분이 지나도 코드가 안 나오면 풀이를 참고한다.
- 풀이를 봤으면 README의 `풀이 방식`에 `풀이 참고`로 기록한다.
- 풀이 참고 문제는 복습일에 다시 푼다.
